# first-project-prof

Я начинаюший программист и для того, чтобы развивать свои навыки, я собираюсь заняться разработкой своего маленького личного проекта. Проект сам по себе будет небольшим клоном одной игры на Unity - Getaway Shootout. Пиксельная игра, в которой нужно прыжками добраться до конца уровня, попутно отбиваясь от соперников с помощью расположенного на карте оружия. 

Главным преимществом игры для меня был локальный кооператив на одном экране(split screen) и быстрый, затягивающий геймплей, использующий простую, но увлекательную физику. Однако главными проблемами были просадки темпа на некоторых картах, примитивность некоторых аспектов игры и репетативность.

Для решения этих проблем будут созданы новые карты, более подходящие для скорости игры, и внедрена небольшая система рандомизации условий. 

Для разработки будет использоваться игровой движок Unity, для рисования спрайтов Aseprite, для музыки и звуков ... 

Два игрока будут должны добраться до конечной точки уровня, победителем раунда будет тот игрок который доберётся до неё первым. Для того чтобы помешать сопернику на карте будут размещены точки со случайным оружием и активируемые ловушки.
Для того чтобы внести разнообразие в игровой процесс, в некоторых раундах будут подключаться случайные условия(изменение гравитации, дождь, отзеркаливание карты или её сегментов и т.д.)
