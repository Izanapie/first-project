# first-project-prof

Я начинаюший программист и для того, чтобы развивать свои навыки, я собираюсь заняться разработкой своего маленького личного проекта. Проект сам по себе будет небольшим клоном одной игры на Unity - Getaway Shootout. Пиксельная игра, в которой нужно прыжками добраться до конца уровня, попутно отбиваясь от соперников с помощью расположенного на карте оружия. 

<img width="801" height="468" alt="image" src="https://github.com/user-attachments/assets/f2ff902f-ac0b-465f-99b9-e3b84c1e465d" />

Главным преимществом игры является быстрый, затягивающий геймплей, использующий простую, но увлекательную физику. Однако главными проблемами являются:
1) Просадки темпа на некоторых уровнях
2) Примитивность некоторых аспектов игры
3) Репетативность, идеальный маршрут прохождения уровня довольно быстро заучивается

Для решения этих проблем будут разработаны:
1) Более динамичные уровни
2) Небольшая система рандомизации условий 

Для разработки будут использоваться:
1) Игровой движок Unity и его физический движок Box2D
2) Aseprite для рисования спрайтов 

Два игрока будут должны добраться до конечной точки уровня, победителем раунда будет тот игрок который доберётся до неё первым. Для того чтобы помешать сопернику на карте будут размещены точки со случайным оружием и активируемые ловушки, использующие физику.
Для того чтобы внести разнообразие в игровой процесс, в некоторых раундах будут подключаться случайные условия(изменение гравитации, дождь, отзеркаливание карты или её сегментов и т.д.). Подобные мелкие изменения сильно влияют на мышечную память, игроку придётся адаптироваться
